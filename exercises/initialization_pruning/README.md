# 初始化上界剪枝练习

由你修改 `src/minicolmap/mapper.py` 的 `initialize_map`。本目录只提供验收测试，没有替你实现剪枝，也没有修改生产算法。

完整任务、正确性证明、诊断字段、可选排序与实测方法见 [开发指导](../../docs/12-初始化上界剪枝练习.md)。

从项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pytest exercises/initialization_pruning -q
```

共 **25 项**测试。提供练习时的实测基线为 **10 失败、15 通过**：

- 8项失败：较弱候选仍进入G6、G8、三角化或两视图精化，包含启用/关闭diagnostics两种调用。
- 1项失败：尚未记录剪枝的结构化诊断。
- 1项失败：尚未利用保持不下降的最好点数上界跳过候选。
- 15项通过：原有评分、失败回退、输入不变、平局规则及真实几何结果保持正常。

这些失败是待完成的优化要求，不代表原有重建算法失效。练习位于默认 `tests/` 回归目录之外，不使用skip或xfail，也不依赖真实照片、历史输出或固定运行秒数。

先保持原候选顺序实现安全剪枝；按匹配数降序检查属于可选扩展。25项测试允许两种检查顺序，但要求结果和原有平局裁决一致。
