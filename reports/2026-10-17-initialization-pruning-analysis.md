## 实现与测试检查

实现保留了关键正确性条件：仅在存在合格的当前最佳候选后剪枝；上界采用匹配数，比较基准采用最终有效唯一轨迹数；严格使用 `<`，保留同点数候选竞争视差的机会；完全平局时用原始输入下标保持旧裁决；排序不修改调用者传入的列表。

运行命令：

```powershell
.\.venv\Scripts\python.exe -m pytest tests exercises -q -p no:cacheprovider --basetemp .cache/pytest-pruning-regression-20261017
```

结果：**285 passed，16.50 秒**，包含 25 项初始化剪枝验收测试。唯一警告来自 Starlette/httpx 测试依赖弃用，与剪枝结果无关。

另有一个兼容性问题留给用户修改：`mapper.py` 新增 `from typing import NotRequired`，但项目仍声明 Python >=3.10。`typing.NotRequired` 从 Python 3.11 才加入，3.10 会导入失败。`InitialPairReport` 已经 `total=False`，可以直接将三个新增字段写为 `bool`、`int`、`int` 并移除该导入，保留相同的可选键含义。当前 Python 3.12 环境不受影响，以上测试也没有覆盖 Python 3.10。

版本依据：[Python 官方 typing.NotRequired 文档](https://docs.python.org/3/library/typing.html#typing.NotRequired)。

## 后续优化重点

初始化只占最新总时间的 0.92%，即使完全消除也最多节省约 1.1 秒。当前 F-RANSAC 的 81.003 秒占总时间 **67.96%**、匹配阶段 **88.82%**，应优先测量每对的匹配数、实际采样迭代数、退化样本数及八点法/评分/重拟合耗时，再确定下一项练习。

保持同一数据、配置、运行环境和输出质量对照。下一轮先区分“迭代次数太多”和“每次迭代太贵”；现有 515 次计数是调用的图像对数量，并非 515 次 RANSAC 采样。增量建图占约 17.9%，可作为第二优先级。
