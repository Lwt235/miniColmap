## 先统一表示

球谐 degree 最大为 3，包含 degree=0,1,2,3 四个频带，每个通道 `(3+1)^2=16` 个系数，每个高斯共 48 个颜色参数。
这里的“3阶”不是只使用3个系数。

状态固定五组可训练张量：

| 键 | 形状 | 解码 |
|---|---|---|
| `means` | G×3 | 归一化世界坐标 |
| `log_scales` | G×3 | `exp` |
| `quaternions` | G×4 | wxyz，归一化后构造旋转 |
| `sh_coeffs` | G×(L+1)²×3 | 实球谐，最后一维 RGB |
| `opacity_logits` | G | `sigmoid` |

S1 新签名末尾增加 `sh_degree=3`。将点云 RGB 初始化为 DC 项：

```text
C0 = 1 / sqrt(4*pi)
sh_coeffs[:,0,:] = (colors - 0.5) / C0
sh_coeffs[:,1:,:] = 0
```

颜色0/1可以直接表示，不再取 logit，也不需要原来的 epsilon 截断。
S1 仍须返回独立可训练叶张量。S5 拓扑更新必须完整复制所有球谐系数，不能只复制 DC。

## 新增必修 S6：evaluate_sh

```python
evaluate_sh(sh_coeffs, directions, degree=3)  # -> (G,3)
```

`directions` 是世界系中从**相机中心指向高斯中心**的向量：

```text
C = -R.T @ t
d = normalize(means - C)
color = clamp_min(0.5 + sum_k(sh_coeffs[k] * Y_k(d)), 0)
```

方向在 S6 内归一化，方向的范数不能改变颜色。不要把它取反，也不要乘 R 变成相机局部方向。相机中心与高斯中心重合时方向无定义，调用方先剔除非正深度项，S6 对传入的零向量报错。
旋转相机但不改变世界相机中心时，同一高斯的 SH 颜色不变；移动相机才改变观测方向。

沿用原始实现的实球谐顺序 `k=l*l+l+m`，`m=-l..l`。令单位方向为 `(x,y,z)`：

| 索引 | 基函数 |
|---|---|
| 0 | `1/sqrt(4*pi)` |
| 1,2,3 | `-a*y, a*z, -a*x`，`a=sqrt(3/(4*pi))` |
| 4,5 | `b*x*y, -b*y*z`，`b=sqrt(15/(4*pi))` |
| 6 | `sqrt(5/(16*pi))*(2*z*z-x*x-y*y)` |
| 7,8 | `-b*x*z, sqrt(15/(16*pi))*(x*x-y*y)` |
| 9 | `-sqrt(35/(32*pi))*y*(3*x*x-y*y)` |
| 10 | `sqrt(105/(4*pi))*x*y*z` |
| 11 | `-sqrt(21/(32*pi))*y*(4*z*z-x*x-y*y)` |
| 12 | `sqrt(7/(16*pi))*z*(2*z*z-3*x*x-3*y*y)` |
| 13 | `-sqrt(21/(32*pi))*x*(4*z*z-x*x-y*y)` |
| 14 | `sqrt(105/(16*pi))*z*(x*x-y*y)` |
| 15 | `-sqrt(35/(32*pi))*x*(x*x-3*y*y)` |

输出沿用原版的 `+0.5` 与下界截断，**不做 sigmoid，也不截断上界**。训练中的 SH 颜色和合成 RGB 可以超过1，PNG 编码时才截断到 `[0,1]`。S4 因此改为接受有限非负颜色；opacity 与背景仍在 `[0,1]`。
基函数排列与颜色激活核对自[原版 SH 工具](https://github.com/graphdeco-inria/gaussian-splatting/blob/main/utils/sh_utils.py)和[原版 CUDA 前向计算](https://github.com/graphdeco-inria/diff-gaussian-rasterization/blob/main/cuda_rasterizer/forward.cu)。

请保留系数和方向两条梯度路径，包括方向归一化；不要 NumPy/detach。degree 小于最大容量时，未启用的系数梯度必须为零。空输入输出 `(0,3)`，错误输入报 `ValueError`。精确契约见算法函数 docstring。

## 参数、逐阶激活与保存

`gaussian` 配置增加：

```json
{
  "sh_degree": 3,
  "sh_degree_interval": 0,
  "backend": "reference"
}
```

`sh_degree_interval=0` 直接启用全部阶数，便于小规模数学实验。设为1000时，从 DC 开始，每1000步提高一阶，`active_degree=min(sh_degree,step//interval)`，第3000步达到3阶。数组容量不随升阶变化。周期预览、最终验证和重新打开模型都使用该步实际启用的 degree。
这只是球谐升阶约定；当前统一 Adam/MSE、固定尺度初值和选修 S5 仍是教学取舍，不能称为原论文完整训练复现。

3DGS checkpoint 升为 schema 2，记录 `color_model=real_sh`、完整 SH 系数、激活 degree、位姿及归一化信息。NeRF 原 schema 1 权重仍可打开。旧 RGB-only 3DGS 权重明确拒绝，不当成球谐权重加载。
`gaussians.npz` 保存原始 SfM 世界坐标的 means、scales、covariances，另保存 quaternions、完整 sh_coeffs、opacity、degree 和方向约定。归一化只有平移和正尺度，SH 世界方向与系数不需要旋转。
重新渲染不能只读取一组固定 RGB 来代替球谐外观。

## gsplat 后端边界

已提供 `gaussian_backend.py` 和 `configs/3dgs_gsplat.json`，适配固定版本 **gsplat 1.5.3**。加速路径仍由你的 S1 初始化、S2 求三维协方差、S6 求球谐颜色；将可微协方差和颜色传入 CUDA 库，由库完成投影、tile 分组/排序和光栅合成。S3/S4 继续作为你自己的可解释参考及数学验收。
这是显式借助库实现的部分，不能把库内核记为自己手写。调用约定依据[固定版本的 rasterization API](https://github.com/nerfstudio-project/gsplat/blob/v1.5.3/gsplat/rendering.py)，CUDA 分块流程见[官方文档](https://docs.gsplat.studio/main/apis/rasterization.html)。

该适配层要求 CUDA float32，pinhole K 必须为无 skew 的标准内参（允许 K 的整体齐次缩放）。遇到带 skew 的 K 明确拒绝，使用 reference 仍保留原来的完整 K。`eps2d=.3`，classic 模式；渲染近远裁剪与 NeRF 的单位射线采样区间分别处理。

首次框架交付时只有CUDA PyTorch；目前gsplat1.5.3已编译并完成真机验证。普通工作台选择gsplat+CUDA，或导入`configs/3dgs_gsplat.json`。复验与重新搭建步骤见[GPU指南](15-GPU环境与训练启动.md)：

`import gsplat` 成功还不够，必须真实运行前向/反向，确认不是首次调用才发现编译失败。以小型正深度/旋转各向异性/前后遮挡场景与 reference 对照；光栅截断、低通、极小 alpha 和像素约定差异需单独解释，不要求没有依据的逐位相等。

## 最终实时界面与性能门槛

前端与服务连接由我负责，现已接入本机常驻 CUDA 渲染进程：

1. 打开训练结果时加载真实 checkpoint 一次，模型驻留 GPU；关闭会话释放资源。
2. 使用自由观察相机，交互时发送当前K/R/t；支持对齐已有相机，对齐后仍可自由移动。当前3DGS面板采用即时对齐。
3. WebSocket 双向传递相机序号与帧；最多一帧在途，新姿态覆盖待处理请求，旧会话/乱序帧丢弃。连续移动时显示最近完成帧并立即请求最新姿态，不因不断输入而一直丢帧。
4. RGB 帧走二进制传输并记录编码/传输/显示耗时；不逐帧重新加载 checkpoint，不把 JSON 点云或固定预览图当成高斯渲染。
5. 页面显示当前分辨率、实际高斯数、SH degree、后端、新图像FPS，以及GPU渲染、编码和端到端毫秒数；窗口缩放、断线重连、关闭和训练占用GPU有明确状态。

使用方法见[工作台说明](10-可视化工作台.md)。当前只允许一个实时会话，训练/SfM启动与会话互斥；先关闭实时视图再运行新任务。WS地址为`/api/rendering/runs/{run_id}/live`，服务主进程不导入Torch；非法相机、丢失扩展/权重及渲染超时会明确报错并释放子进程。默认JPEG质量85，渲染与编码计时分别报告，画面显示压缩不改变训练权重。

本轮真实模型的图像对照、性能记录和浏览器验收见[分辨率与实时报告](../reports/2026-10-18-3dgs-resolution-live/README.md)。下列10万高斯性能仍是后续规模目标。
