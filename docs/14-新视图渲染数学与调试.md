# 新视图渲染：公式、契约与排错

对应 [开发指南](13-NeRF与3DGS开发指南.md) 与 `rendering/algorithms.py` 的 N1–N4、S1–S5。这里给关系式和实现检查点，函数体仍由你完成。

## N1：从已有相机生成世界射线

项目沿用 `Xc = R Xw+t`。对像素 `p=[u,v,1]`：

```text
C = -Rᵀ t
d_camera = K⁻¹ p
d_world = normalize(Rᵀ d_camera)
X(distance) = C + distance * d_world
```

批量张量使用行向量时，`d_world = d_camera @ R`。不要把 R 和 Rᵀ 混用。对单位姿态的主点像素，射线方向应为 `[0,0,1]`。先用这个例子，再用非单位旋转/平移检查世界相机中心。

K 可以有 skew，不能只写 `(u-cx)/fx` 而忽略交叉项。像素输入为整数中心；在本项目中无需再加 0.5。

图片缩放是另一件事。OpenCV 从旧宽高到新宽高的采样关系为 `u_new=(u_old+0.5)*sx-0.5`，因此工程适配器使用：

```text
A = [[sx, 0, (sx-1)/2], [0, sy, (sy-1)/2], [0,0,1]]
K_new = A @ K_old
```

射线方向单位化后，t 是物理射线长度。若未单位化，N3 的密度积分不能直接使用相同 delta，否则边缘射线会改变不透明度。

## N2 / N4：位置、方向与可训练表示

编码按每个频率成对拼接：

```text
gamma(x) = [x, sin(pi*x), cos(pi*x), sin(2*pi*x), cos(2*pi*x), ...]
```

保留任意批次前导维度，编码只扩展最后一维。N4 的密度分支只消费位置，颜色分支同时消费位置特征与方向编码。将密度设为非负、颜色约束到 `[0,1]`；保证所有层是注册的子模块，而不是存在普通 Python list 中的未注册层。

先检查固定 xyz、改变方向时密度不变，再检查颜色确实能对方向产生响应。之后检查参数数目、梯度、`.to()`、保存加载是否都工作。这个教学 MLP 不规定论文的每层宽度，但至少两层隐藏层，不能只返回常量来通过形状检查。

## N3：把颜色与密度变成像素

对一条射线的 S 个非递减采样距离：

```text
delta[i] = t[i+1]-t[i]             i < S-1
delta[S-1] = far-t[S-1]
alpha[i] = 1-exp(-sigma[i]*delta[i])
T[i] = product(1-alpha[j], j<i)
w[i] = T[i]*alpha[i]
rgb = sum(w[i]*color[i]) + (1-sum(w))*background
opacity = sum(w)
depth = sum(w[i]*t[i])
```

T 是不包含当前 alpha 的前缀积；少平移一个位置会让第一层错误地衰减自己。可使用数值稳定的指数形式，但不能用任意 epsilon 修改可手算的物理结果。

当前训练器从 near 起取均匀左端点，最后一段有限，完整覆盖 `[near,far]`。没有无限长末段，也没有隐藏的 coarse/fine 采样。sigma=0 时应完整返回背景、不透明度0；常密度介质的总不透明度应为 `1-exp(-sigma*总长度)`。

返回的 depth 是未除 opacity 的累积深度，不能悄悄改成命中条件均值。空批次返回形状正确的空张量；负密度、乱序 t、far 小于最后样本都要明确拒绝。

调试顺序：单样本 → 两层手算 → 透明背景 → 常密度 → gradcheck → 用 Adam 调整 RGB/密度使目标像素误差下降。

## S1 / S2：从点到椭球

每个高斯状态包含五组可训练量：

```text
means                 G×3
log_scales            G×3
quaternions (wxyz)    G×4
color_logits          G×3
opacity_logits        G
```

使用 `scale=exp(log_scale)`、`RGB=sigmoid(color_logits)`、`opacity=sigmoid(opacity_logits)`。四元数归一化后形成旋转 Q：

```text
Sigma_world = Q @ diag(scale²) @ Qᵀ
```

先验收单位四元数，再用旋转且三个尺度不同的例子检查非对角项。把协方差简化为球或轴对齐矩阵会失去测试要求的各向异性。q 和 -q 表示同一旋转；零四元数不能除以零后继续。

S1 要创建独立可训练叶张量，不可让高斯参数与原始点数组共享可修改存储。初始 colors 的0/1在取 logit 前夹到 `[1e-6,1-1e-6]`。

## S3：透视投影与屏幕椭圆

先把均值和协方差变换到相机系：

```text
mu_c = R @ mu + t
Sigma_c = R @ Sigma_world @ Rᵀ
mu_2d = project(K @ mu_c)
Sigma_2d = J @ Sigma_c @ Jᵀ + min_variance*I
```

J 是像素投影对相机坐标的 2×3 Jacobian。对于允许 skew 的 K，令 `a=fx*x+skew*y+cx*z`、`b=fy*y+cy*z`：

```text
J = [[fx/z, skew/z, -(fx*x+skew*y)/z²],
     [0,    fy/z,   -fy*y/z²]]
```

用独立有限差分检查 J，再测试旋转后协方差。`min_variance` 是像素平方的方差，不是标准差。S3 只把正深度判为可见，不因中心在图外就裁掉整个高斯；椭圆尾部仍可能覆盖边缘。

非正深度的输出使用有限占位中心与协方差，visible=False，避免在未选分支中提前产生 NaN。保持原长度及原索引，过滤发生在训练器送入 S4 时。

## S4：前后遮挡与可微合成

将正深度高斯按从近到远排序，同深度保持原序。对整数像素 p：

```text
q = p-mu_2d
g = exp(-0.5 * qᵀ @ inverse(Sigma_2d) @ q)
alpha = clamp(opacity*g, 0, 0.99)
```

按 N3 的排他透射率合成 RGB 与 depth，余下透射率贡献背景。这里 depth 是对应高斯相机 z 的加权和，与 NeRF 的射线距离不同，不能无说明地直接作深度图数值对照。

不要在渲染后按所有高斯的权重重新归一化颜色，这会消除不透明度与背景的意义。测试的前红后蓝例子可直接发现排序颠倒。另一测试只改变颜色/opacity 用 Adam 降低像素误差，能发现输出被 `.detach()`、NumPy 或错误重建张量切断。

第一版允许朴素广播/循环，先正确后加速。它与原版 tile/CUDA 光栅器的性能不同；高斯数和像素数要从小开始。空高斯返回纯背景及零深度/opacity。

## S5：把拓扑更新与梯度更新分开

这是选修的确定性规则，完整条件以 docstring 和测试为准：先按 opacity 筛选并保留原序，在剩余上限内给高梯度项追加子项；实际产生子项的源与子尺度减半，子中心沿旋转后的局部 x 轴移动原最小尺度，原中心不动。

输出独立的叶张量。旧 Adam 的参数引用和动量不再对应新数组，当前工程循环直接重建优化器。这是明确的教学取舍，不是保留了原论文完整密度策略。

## 训练失败时按现象检查

| 现象 | 先检查 |
|---|---|
| 全背景且无学习 | near/far 是否覆盖物体、单位射线、密度初值、高斯正深度、透明度 |
| 镜像或倒置 | R/Rᵀ、world-to-camera、RGB行列顺序、Three到CV轴转换 |
| 有图但 loss 不降 | 参数是否注册、可微路径是否被切断、学习率、是否误用验证图训练 |
| 椭圆方向错误 | 四元数wxyz、旋转协方差、J的坐标系 |
| 越远高斯反而遮住近点 | 深度排序与排他透射率 |
| 图像缩小后对不齐 | K完整缩放及半像素关系，不能只缩fx/fy |
| 保存后渲染不一致 | 配置/状态字典、归一化、渲染camera是否来自原世界系 |
| 内存或时间迅速上升 | 先减图像分辨率与高斯数；CUDA设备不等于tile光栅加速 |
