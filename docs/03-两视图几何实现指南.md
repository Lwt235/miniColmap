# 两视图几何实现指南

目的：把真实像素对应变成相对位姿和任意尺度结构。先用手算与合成点验证，再接SIFT。
这里给出数学任务与调试线索；核心代码由你实现。所有函数定义和边界见 geometry.py。

## G1：投影，约0.5–1小时

从相似三角形推导 `uv = (K Xc)_[:2] / z`，行存储先 `Xc=X@R.T+t`。
以K焦距800、主点(320,240)、X=(1,1,5)、R=I、t=0验证得到(480,400)。
再把相机中心改为(1,0,0)，t=(-1,0,0)；此时同一个点横坐标回到320。
返回depth用于调用方过滤，不能取绝对值。空数组返回空；接近零深度报错。

## G2/G3：归一化八点法，约3–4小时

像素量级可能上千，直接构造A会放大病态。每组点分别移到质心，然后缩放至均距√2：

\[
c=\frac1N\sum_i x_i,\quad d=\frac1N\sum_i\|x_i-c\|,\quad s=\frac{\sqrt2}{d},
\quad T=\begin{bmatrix}s&0&-sc_x\\0&s&-sc_y\\0&0&1\end{bmatrix}.
\]

由 `(u2,v2,1) F (u1,v1,1)^T=0` 得到每行：

\[
[u_2u_1,\ u_2v_1,\ u_2,\ v_2u_1,\ v_2v_1,\ v_2,\ u_1,\ v_1,\ 1].
\]

1. 分别归一化两组像素，构造A(N,9)，检查退化。
2. 对A做SVD，最后右奇异向量reshape成3×3。
3. 对Fhat做SVD，将最小奇异值设0；反归一化 `F=T2.T@Fhat@T1`。
4. 归一化F的Frobenius范数；符号不影响极线，不直接比较元素符号。

**恰好8点时A是8×9，必须保留完整Vh(9×9)。** `full_matrices=False`只给8个右向量，
会丢零空间；RANSAC里这个错误尤其隐蔽。[NumPy SVD](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html)
无噪声非退化最小样本rank(A)=8；一般含噪超定A可rank9，不要因此拒绝所有有噪数据。
rank<8、重复/共线、特定平面退化需拒绝。用确切8点与多点分别测试。

自测：为什么F仅有比例意义？9元素为什么至少需8对？两组点为什么分别用T1/T2？

## G4/G5：Sampson 与 RANSAC，约3–4小时

记l2=F x1、l1=Fᵀx2、e=x2ᵀF x1，则

\[
d_S=\frac{e^2}{l_{2x}^2+l_{2y}^2+l_{1x}^2+l_{1y}^2}.
\]

它是几何误差的一阶近似，单位px²。分母0，包括0/0，要返回inf以拒绝。
非零比例乘F不改变结果。测试手算偏差2px的例子，避免把平方距离又平方一次。

RANSAC每轮从N对中抽8个不同对应→G3→G4→统计 `d_S <= threshold_px²`，跳过退化样本。
选择最大内点数，平手可看内点median；最终用所有内点重估并从**返回F**重新生成mask。
使用 `default_rng(seed)`，不要依赖全局随机状态。完全退化应报失败。

八点法抽全内点的概率是w⁸，目标置信p的估计轮数：

\[
N_{trial}\ge\frac{\log(1-p)}{\log(1-w^8)}.
\]

w=.5、p=.99约1177轮；w=.3约7万轮。因此2000只是硬预算，不能宣称永远99%成功。
先固定预算通过公开测试，后续加入自适应上限并记录实际轮数/到达上限。
调试时记录样本失败率、内点数、refit前后变化；不要把阈值放宽到所有对应都成内点。

## G6/G8：从E恢复位姿，约3–4小时

用 `E=K2.T@F@K1`；理想E有奇异值(s,s,0)，取前两个均值进行约束投影。
用K逆将像素标定为射线，首相机作为世界系 `R1=I,t1=0`。
若 `E=UΣVᵀ`，可用

\[
W=\begin{bmatrix}0&-1&0\\1&0&0\\0&0&1\end{bmatrix},\quad
R\in\{UWV^T,UW^TV^T\},\quad t\in\{+U_{:,3},-U_{:,3}\}.
\]

先处理SVD符号使候选R为det+1，不能把反射当旋转。
四个候选逐一用G7三角化，并统计两图正深度、有限且有视差的点。
同一坐标系下的射线夹角需要把camera2射线用Rᵀ转回世界；点X也可通过X−C1、X−C2求角。
G8 API用1e-3 rad作为数值最低角度，mapper再用配置的1.5°做实际点质量过滤。
点数最多的候选仍要达到API的8个可用点；纯旋转与过低视差应换初始化对。

此时t只恢复方向，令||t||=1定义地图单位；相机中心是−Rᵀt。
测试必须含非单位旋转，只有平行相机无法发现R/Rᵀ错误。
不要将 `cv2.recoverPose` 或GT位姿作为G8答案；可以另作参考对照。

## G7：DLT三角化，约2小时

从 `x×PX=0` 每幅取两行，两个视角得到

\[
A_X=\begin{bmatrix}u_1P_{1,3}-P_{1,1}\\v_1P_{1,3}-P_{1,2}\\
u_2P_{2,3}-P_{2,1}\\v_2P_{2,3}-P_{2,2}\end{bmatrix}.
\]

取最小右奇异向量Xh，以第四分量齐次除法还原X。
若齐次分母近0、两相机重合导致解不唯一、非有限，返回整行NaN让mapper拒绝。
有噪时AX一般满秩，不能把rank4当成失败；需要拒绝的是欠约束/不唯一、无穷远和后续质量差。
DLT会给负深度点，不在这个函数取绝对值或强行删除行，否则mask无法对应原关键点。
线性代数残差小不代表可靠几何；最终要正深度、视差与各视图重投影共同验收。

## 几何阶段调试表

| 现象 | 优先检查 |
|---|---|
| 恰好8点失败、多点似乎正常 | SVD full_matrices与F元素顺序 |
| 所有Sampson内点突然消失 | x1/x2方向、F转置、阈值是否平方 |
| 点云在相机后方 | 四解t符号、相机中心/平移混淆 |
| 旋转图对失败、平行图对正常 | R/Rᵀ与坐标变换方向 |
| 很低误差但点在极远处 | 小基线、纯旋转、缺少视差过滤 |
| 换分辨率后误差大 | K未同步缩放，或像素/归一化混用 |
