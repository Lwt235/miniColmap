# 配置结构与 mapper 参数参考

## config 具体是什么

`initialize_map`、`register_next_image`、`triangulate_new_tracks` 接收 **完整流水线配置字典**，
对应 `config.py` 的 `PipelineConfig`。`config["mapping"]` 只是其中一节。
运行时仍是dict；TypedDict提供键名和类型提示，运行时校验由 `load_config` 完成。
K、位姿、图像尺寸从model读，track和颜色分别从tracks与feature_colors读，不放在config中。

```python
from minicolmap.config import load_config
from minicolmap.mapper import initialize_map

config = load_config()  # 默认值；也可load_config("configs/my_scene.json")
mapping = config["mapping"]
angle_deg = mapping["min_angle_deg"]
max_error_px = mapping["max_reprojection_px"]
initialize_map(model, pairs, tracks, config, feature_colors)
# 传整个config；不要只传mapping。
```

## 完整结构与默认值

默认数值以 `configs/default.json` 与 `config.py:DEFAULT` 为准，下面与当前版本一致：

```json
{
  "seed": 0,
  "features": {
    "max_features": 4000,
    "ratio": 0.75
  },
  "geometry": {
    "threshold_px": 1.5,
    "max_trials": 2000,
    "confidence": 0.99,
    "min_trials": 20,
    "min_inliers": 30
  },
  "mapping": {
    "min_pnp_points": 15,
    "pnp_threshold_px": 3.0,
    "min_angle_deg": 1.5,
    "max_reprojection_px": 3.0
  },
  "bundle_adjustment": {
    "enabled": false,
    "max_nfev": 50,
    "loss": "huber",
    "f_scale": 1.0
  }
}
```

## mapper 使用的字段

| 访问路径 | 类型、默认值 | 单位/范围 | 使用阶段与含义 |
|---|---|---|---|
| config["geometry"]["min_inliers"] | int，30 | 个数，≥8 | 上游接纳图像对的最低F内点数；M1也沿用为**全部几何过滤后**有效初始3D点数的下限 |
| config["mapping"]["min_pnp_points"] | int，15 | 个数，≥6 | M2调用PnP前的唯一2D–3D对应数，以及PnP和最终过滤后保留的内点数，都必须达到它 |
| config["mapping"]["pnp_threshold_px"] | float，3.0 | 欧氏像素距离，>0 | M2传给solve_pnp的threshold_px，包装内用于PnP-RANSAC及细化后重新评分；传入时不平方 |
| config["mapping"]["min_angle_deg"] | float，1.5 | 度，0<角度<180 | M1/M3最小三角化视差角；与arccos结果比较前用np.deg2rad转换为弧度 |
| config["mapping"]["max_reprojection_px"] | float，3.0 | 欧氏像素距离，>0 | M1/M3候选点在**每幅相关已注册图**的误差上限；M2追加观测也用这个门槛 |
| config["seed"] | int，0 | 非负整数 | M2传入PnP包装；上游F-RANSAC也使用它，不是实体ID |

float字段也可以在JSON里写整数，例如3；加载器检查数值范围，不强制把整数转为float。
当前没有独立的 `min_initial_points`、`min_pnp_inlier_ratio`、`min_depth` 配置键。
M1沿用已有geometry.min_inliers，是现在明确下来的首版约定；若要单独设置初始化点数，需同步扩展默认值、校验、类型与测试。
深度检查沿用几何函数的正深度/近零数值约定，不是某个米制距离阈值。

### M1：初始化

- pairs已经过上游F-RANSAC；不需用geometry.threshold_px再次估计F。
- 用mapping.min_angle_deg和mapping.max_reprojection_px过滤候选点。
- 有效点数≥geometry.min_inliers后再提交初始地图；不足则换候选对。
- G8内部1e-3 rad是数值最低视差门槛，不能替代mapping中配置的质量门槛。
- 线性初值通过基本正深度/视差检查后执行两视图精化，再重新应用质量门槛。
  精化固定首pose和单位基线，默认预算100次函数评估，独立于最终地图BA的开关/预算。
  精化预算目前是 `refine_two_view` 的函数默认参数，不是JSON配置键。

### M2：注册

调用 `register_next_image(model, tracks, config)`，只需地图、tracks和完整配置。
pair数据用于M1初始化，M2不读取它。

1. 构造唯一2D–3D对应；不足min_pnp_points就尝试其他图。
2. 将pnp_threshold_px和顶层seed传入PnP包装，取得R/t与内点mask。
3. 仅保留正深度、PnP内点且误差≤max_reprojection_px的观测。
4. 最终数量仍须≥min_pnp_points，再写入Pose与观测；失败不得部分修改地图。

PnP包装自身只保证至少6个有效内点，mapper仍须执行默认15点政策。
两个像素阈值默认同为3，但用途不同：若PnP阈值3、观测门槛2，最终以更严格的2px过滤追加观测。
目前没有内点率门槛；可记录比率作诊断，不增加未经说明的隐藏阈值。

### M3：新增点

每个尚未成点的track至少有两幅已注册观测；选择视差角足够的一对三角化，
在所有相关已注册图检查正深度与max_reprojection_px。
一条合法track就允许新增1点，不要求凑够geometry.min_inliers个新点；min_pnp_points也不控制track长度。

## 其他字段由谁使用

| 字段 | 类型、默认值、范围 | 使用位置 |
|---|---|---|
| features.max_features | int，4000，≥2 | SIFT特征数参数，不是mapper点数上限 |
| features.ratio | float，0.75，0<值<1 | 前端双向描述子ratio筛选，不是PnP内点率 |
| geometry.threshold_px | float，1.5，>0 | 上游F-RANSAC；G4返回px²，G5内部与阈值平方比较 |
| geometry.max_trials | int，2000，≥1 | 上游F-RANSAC采样硬上限，不控制PnP或BA |
| geometry.confidence | float，0.99，0<值<1 | 自适应F-RANSAC目标置信度；不是内点率，达到硬上限时未必达到目标 |
| geometry.min_trials | int，20，≥1 | 自适应停止前的最少抽样数；超过max_trials时硬上限优先 |
| bundle_adjustment.enabled | bool，false | pipeline决定建图后是否调用BA |
| bundle_adjustment.max_nfev | int，50，≥1 | 优化器函数评估预算，不等同于固定50次优化迭代 |
| bundle_adjustment.loss | Literal，huber | 允许linear/huber/soft_l1，优化器损失 |
| bundle_adjustment.f_scale | float，1.0，>0 | 优化器残差像素尺度 |

最终地图BA由pipeline调度；M1内部的两视图精化是初始化步骤。

前端“参数 → 几何验证”可编辑confidence/min_trials，并支持配置导入、导出和恢复默认。
旧JSON没有这两个字段时自动补0.99/20。令min_trials=max_trials可用于固定采样预算对照。
`refine_model` 的settings参数传 `config["bundle_adjustment"]` 子字典。
PnP包装中的2000次采样与0.999置信度目前是其内部常量，不受geometry.max_trials或BA预算控制。
所有默认阈值都是起始实验设置，不保证适用于所有场景。

## 如何覆盖参数

可以创建 `configs/my_scene.json`，只写覆盖项：

```json
{
  "seed": 42,
  "mapping": {
    "min_pnp_points": 20,
    "max_reprojection_px": 2.0
  }
}
```

`load_config("configs/my_scene.json")` 补齐其他默认项、检查范围并拒绝未知键。
不要把这份仅含覆盖项的原始JSON直接传给mapper，否则会缺节或缺字段。
每次load_config返回独立字典，不会修改DEFAULT或其他配置对象。
直接修改加载后的dict不会自动重新校验；正式运行优先保存JSON再通过load_config读入。
CLI用 `--config configs/my_scene.json`，完整合并结果保存到本次output/config.json。
